# Simulated MTA Dataset

This folder contains simulated data for Markov Chain Attribution, Shapley Value Attribution, and ROI/ROAS calculation.

## Files

- `user_touchpoint_events.csv`: raw user-level touchpoint events.
- `markov_user_paths.csv`: ordered user paths for Markov attribution.
- `shapley_user_channel_sets.csv`: user-level channel sets for Shapley attribution.
- `channel_spend.csv`: channel-level spend for ROI/ROAS calculation.

- users: 3000
- events: 10974
- converted_users: 768
- non_converted_users: 2232
