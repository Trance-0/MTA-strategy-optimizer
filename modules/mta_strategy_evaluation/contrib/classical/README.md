# Classical model contribution placeholder

This directory is reserved for the second strategy-evaluation contribution: a
classical, non-neural response model. Contributor-owned scripts, documentation,
data, and recorded results belong here unchanged. Project integration belongs in
`modules/mta_strategy_evaluation/adapters/`; an adapter may read this directory
but must not rewrite it or require it to be populated for the evaluation stage
to run.

Folders under `contrib/` are named after the kind of model they hold, not after
the person who wrote it, so a handover between contributors does not rename a
path that code and documentation both cite.
