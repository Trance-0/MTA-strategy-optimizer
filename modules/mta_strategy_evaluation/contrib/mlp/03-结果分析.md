# 结果分析：SK-II 扩样后准确度

| 项 | 内容 |
|----|------|
| 版本 | v1.4 |
| 指标文件 | `results/metrics.json` |
| 测试集 | 42 行，**全部真实** July 11–31 |

## 1. 主结论

扩样到 **424** 行后，机制型多任务网在真实测试段的相对误差好于纯 MLP，但 **R² 仍为负**——说明「能训起来、误差量级可用」，尚未学会稳定解释真实日间方差。

| 模型 | Test MAE | Test sMAPE | Test MAPE | Test R² |
|------|----------|------------|-----------|---------|
| MLP | ~2115 | ~37% | ~31% | −4.33 |
| **Multitask** | **~1684** | **~29%** | **~24%** | **−2.72** |

验证集同序：Multitask 优于 MLP。

## 2. 如何读这些数

- **MAPE ≈ 24%**：单日归因交易额量级上，多任务网平均相对偏差约四分之一；做粗预算情景尚可，不宜当精密日预报。
- **R² < 0**：预测方差/偏差仍大于「用均值猜」；扩样来自同一生成器，对真实 July 后半仍有分布差。
- **训练几乎全是合成**：模型学的是「拟合式 + 噪声」；真实测试是诚实压力测。
