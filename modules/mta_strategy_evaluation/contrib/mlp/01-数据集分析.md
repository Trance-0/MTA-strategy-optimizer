# 数据集分析：SK-II 广告预算 → 归因交易额（扩样版）

| 项 | 内容 |
|----|------|
| 版本 | v1.4 |
| 产品 | SK-II（无 ASIN） |
| 真实源 | `amazonTestData/amazon_ads_report_sk2.csv` |
| 面板 | `data/prediction_panel.csv`（424 行） |

## 1. 规模

| 类型 | 行数 | 日期 |
|------|------|------|
| 真实 | 62 | 2025-07，US/CA |
| 模拟 | 362 | 2025-01–06，按真实 July 拟合的对数弹性生成器 |
| 合计 | 424 | 市场×日，无 ASIN |

标记列：`is_synthetic`（0=真，1=模拟）。生成器参数：`data/generator_params.json`。

## 2. 切分

| 分割 | 条件 | 行数 | 说明 |
|------|------|------|------|
| train | ≤ 2025-06-20 | 342 | 几乎全模拟，用于把样本量做大 |
| val | 06-21～07-10 | 40 | 模拟尾 + 真实 July 前段 |
| test | ≥ 2025-07-11 | 42 | **全部真实**，作最终准确度 |

## 3. 标签与特征

- **主标签**：`revenue` = 归因广告交易额（非全站有机 GMV）
- **输入**：四类预算 `log1p` + 份额 + 周末/星期/市场（共 19 维，见 `feature_schema.json`）
- **机制辅助**：四类曝光、`sales_ad`
- **不含**：ASIN、昨日惯性、库存、价格、ridge

## 4. 使用注意

模拟扩大了训练容量，但分布仍锚定在 July 拟合式上；**真实测试 R² 仍可能为负**——扩样改善的是可训性与相对误差（MAPE/sMAPE），不是保证外推到任意真实月。
