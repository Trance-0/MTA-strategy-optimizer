# MTA Research Reading Order

This section contains MTA methodology papers and study notes and is not runtime input. Recommended order:

1. [Data-driven Multi-touch Attribution Models](/research/mta/Data-driven%20Multi-touch%20Attribution%20Models.pdf): MTA problem definition and stability.
2. [Mapping the Customer Journey](/research/mta/Mapping%20the%20customer%20journey.pdf): graph-based and Markov-chain attribution research.
3. [Shapley Value Methods for Attribution Modeling](/research/mta/Shapley%20Value%20Methods%20for%20Attribution%20Modeling%20in%20Online%20Advertising.pdf): Shapley-value attribution background.
4. [Data-driven MTA study notes](data-driven-mta-models-study-note.md): personal supporting notes only.

The [AMC MTA reference index](../../attribution/reference-index.md) defines the project's implemented formulas, fields, and governance.
