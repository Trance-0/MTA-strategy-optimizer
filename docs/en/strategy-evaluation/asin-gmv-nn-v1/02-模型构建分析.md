## 0. 一句话

两套网络共用 **27 维输入**（四类预算 + 份额 + 时间/市场 + P0 placement/创意花费结构）：

- **MLP**：直接预测 \(\log(1+R)\)
- **机制型多任务网**：共享编码器 + 流量 / 效率 / 交易额三头

19 维 Baseline **已从主训练移除**。

## 1. 输入向量（27）

| 下标 | 内容 | 维数 |
|------|------|------|
| 0–3 | `log1p(budget_*)` | 4 |
| 4–7 | `share_*` | 4 |
| 8–9 | `has_ad`, `is_weekend` | 2 |
| 10–16 | `dow` one-hot | 7 |
| 17–18 | `country` one-hot | 2 |
| 19–26 | P0 `share_cost_*` + `n_placement_types` | 8 |

拓扑：**27 → 32 → 16 → 1**（机制网同共享层 + 三头）。

| 模型 | 参数量（约） |
|------|----------------|
| MLP | 1441 |
| Multitask | 1526 |

## 2. 训练

Adam lr=1e-3，Huber on log1p，batch 32，最多 400 epoch，patience 40。  
复现：

```bash
python3 code/build_dataset.py
python3 code/train_models.py
python3 code/export_demo_weights.py   # 可选：demo 权重
```
