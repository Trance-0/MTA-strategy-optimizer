## 0. 一句话

两套网络共用同一套 **19 维输入**（四类预算的 `log1p` + 份额 + 时间/市场）：

- **MLP**：黑盒直接预测 \(\log(1+R)\)
- **机制型多任务网**：共享编码器 + 流量 / 效率 / 交易额三个头，用辅助标签把隐层往「花费→曝光→转化→成交」对齐

## 1. 样本如何变多（模拟扩样）

| 来源 | 行数 | 说明 |
|------|------|------|
| 真实 | 62 | `amazon_ads_report_sk2.csv`，US/CA × 2025-07 |
| 模拟 | 362 | 2025-01-01～06-30，US/CA 每日一行 |
| **合计** | **424** | |

生成式（拟合自真实 July，参数见 `data/generator_params.json`）：

1. 按 **市场 × 星期** 抽预算均值，再乘对数正态扰动，得到 \(B_{SP},B_{SB},B_{SD},B_{DSP}\)
2. 用岭回归拟合  
   \(\log(1+R) \approx a + \sum_g \beta_g \log(1+B_g) + \gamma\cdot weekend + \delta\cdot CA\)
3. 曝光、件数用同类对数线性从预算生成，并加噪声  
4. 标记 `is_synthetic=1`

时间切分：

| 分割 | 日期 | 约行数 | 构成 |
|------|------|--------|------|
| train | ≤ 06-20 | 342 | 几乎全是模拟 |
| val | 06-21～07-10 | 40 | 模拟尾 + 真实 July 前段 |
| test | ≥ 07-11 | 42 | **全部真实 July** |

因此：训练靠模拟把样本量做大；**测试仍盯真实段**，避免「只在假数据上好看」。

## 2. 输入向量（19 维）

顺序与 `design_matrix` 一致：

| 下标 | 内容 | 维数 |
|------|------|------|
| 0–3 | `log1p(budget_sp/sb/sd/dsp)` | 4 |
| 4–7 | `share_sp/sb/sd/dsp` | 4 |
| 8 | `has_ad` | 1 |
| 9 | `is_weekend` | 1 |
| 10–16 | `dow` one-hot（周一…周日） | 7 |
| 17–18 | `country` one-hot（CA / US） | 2 |
| | **合计** | **19** |

训练前对训练集做 **Standardizer**（减均值、除标准差），验证/测试用同一套均值方差。

**没有** ASIN、没有昨日惯性。

主标签：`y = log1p(revenue)`。  
机制网额外标签：`log1p(impressions_*)`（4 维）、`log1p(sales_ad)`。

## 3. 方案 A：MLP 内部结构

### 3.1 拓扑

```text
x ∈ R^19                    # 标准化后的预算+情境
        │
        ▼
   ┌─────────────────┐
   │ Dense: 19 → 32  │  W1 ∈ R^{19×32}, b1 ∈ R^{32}
   │ ReLU            │
   │ Dropout(0.15)   │  仅训练时；推理放大 1/(1-p)
   └────────┬────────┘
            │ h1 ∈ R^{32}
            ▼
   ┌─────────────────┐
   │ Dense: 32 → 16  │  W2 ∈ R^{32×16}, b2 ∈ R^{16}
   │ ReLU            │
   └────────┬────────┘
            │ h2 ∈ R^{16}
            ▼
   ┌─────────────────┐
   │ Dense: 16 → 1   │  W3 ∈ R^{16×1}, b3 ∈ R
   └────────┬────────┘
            │
            ▼
     ŷ = log1p(R̂)   →  还原 R̂ = min(expm1(ŷ), rev_cap)
```

### 3.2 前向公式

\[
\begin{aligned}
z_1 &= x W_1 + b_1,\quad h_1 = \mathrm{ReLU}(z_1)\odot m_{\mathrm{drop}} \\
z_2 &= h_1 W_2 + b_2,\quad h_2 = \mathrm{ReLU}(z_2) \\
\hat y &= h_2 W_3 + b_3
\end{aligned}
\]

### 3.3 参数量

| 层 | 权重 | 偏置 | 小计 |
|----|------|------|------|
| Dense1 | 19×32 = 608 | 32 | 640 |
| Dense2 | 32×16 = 512 | 16 | 528 |
| Out | 16×1 = 16 | 1 | 17 |
| **合计** | | | **1185** |

### 3.4 隐层在「业务上」在干什么（不是逐神经元命名）

| 层 | 结构角色 | 希望吸收的业务信息 |
|----|----------|-------------------|
| h1 (32) | 把四类预算、份额、周末、市场揉成非线性组合 | 总额高低、SP/DSP 结构、周末溢价 |
| h2 (16) | 压缩表示，供线性读出交易额 | 更接近「有效投放强度」的标量场 |
| 输出 | 对数成交额 | 边际递减（因输入已是 log1p） |

神经元**没有**「第 7 个单元 = CTR」这种对应；可解释性靠输入设计 +（机制网的）多任务头，而不是给隐单元起名。

## 4. 方案 B：机制型多任务网内部结构

### 4.1 拓扑

```text
x ∈ R^19
        │
        ▼
   Shared Encoder（与 MLP 同构）
   Dense 19→32 + ReLU + Dropout
   Dense 32→16 + ReLU
        │
        │  h ∈ R^{16}
        ├──────────────────┬──────────────────┐
        ▼                  ▼                  ▼
  Head_revenue       Head_traffic        Head_efficiency
  Dense 16→1         Dense 16→4          Dense 16→1
  log1p(R)           log1p(impr_g)×4     log1p(sales_ad)
  λ_R = 1.0          λ_V = 0.3           λ_E = 0.2
```

### 4.2 损失

各头在对数空间用 **Huber（δ=1）**，再加权：

\[
\mathcal{L} = \lambda_R \mathcal{L}_R + \lambda_V \mathcal{L}_V + \lambda_E \mathcal{L}_E
\]

- 推理交易额：**只用 revenue 头**
- 流量头：逼共享表示记住「预算是否买到曝光」
- 效率头：逼表示记住「是否转化出件数」

### 4.3 参数量

| 块 | 参数 |
|----|------|
| Shared Dense1+2 | 640 + 528 = 1168 |
| Head_rev | 16+1 = 17 |
| Head_traf | 16×4+4 = 68 |
| Head_eff | 16+1 = 17 |
| **合计** | **1270** |

比 MLP 只多约 85 个参数（两个浅头），机制靠**监督信号**，不靠堆深。

### 4.4 反向传播要点

1. 三个头的误差反传到共享的 \(h\) 后相加：  
   \(dh = Wr^\top d_r + Wt^\top d_t + We^\top d_e\)
2. ReLU 处乘指示函数 \([z>0]\)
3. Dropout 掩码在反传时同样乘上（训练时）
4. 权重衰减：每个 \(W\) 的梯度加 \(\lambda_{\mathrm{wd}} W\)（\(\lambda_{\mathrm{wd}}=10^{-4}\)）

## 5. 训练配置

| 项 | 取值 |
|----|------|
| 优化器 | Adam（β1=0.9, β2=0.999） |
| 学习率 | 1e-3 |
| Batch | 32 |
| 最多 epoch | 400 |
| 早停 | 验证损失 patience=40 |
| 初始化 | He / Kaiming（\(\mathcal{N}(0,\sqrt{2/n_{in}})\)） |
| 还原裁剪 | \(R̂ \le P_{95}(R_{\mathrm{train}})\times 2\)，防 `expm1` 爆炸 |

实现：纯 **numpy** 手写前向/反向（无 PyTorch），便于审结构。

## 6. 配比反事实（推理期，非训练结构）

总额不变、只改 SP↔SB 时，网络 alone 学到的替代效应有限（尤其训练多为生成式）。推理可选用先验：

\[
\hat R_{\mathrm{whatif}} = \hat R_{\mathrm{NN}}(B')\cdot
\frac{\sum_g e_g s'_g}{\sum_g e_g s_g},\quad
e=(0.40,0.22,0.16,0.12)
\]

四类预算同比例加减时份额不变，乘数=1，只走网络。
