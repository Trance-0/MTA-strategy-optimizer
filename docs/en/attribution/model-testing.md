# Model Testing and Comparison

Attribution assurance checks a model's internal contracts, compares the models
used for publication, and measures recovery of simulation ground truth. The
[model testing overview](./model-testing/index.md) explains how these layers fit
together; each layer has its own page so a change needs only the relevant context.

## Layer 1 — Unit and Contract Tests {#layer-1--unit-and-contract-tests}

[Unit and contract tests](./model-testing/unit-contract-tests.md) specify model
conformance, report adapters, and the pinned generator integration.

## Layer 2 — Governance Comparison {#layer-2--governance-comparison}

[Governance comparison](./model-testing/governance-comparison.md) specifies
agreement thresholds and the evidence required to publish a recommendation.

## Layer 3 — Ground-Truth Evaluation {#layer-3--ground-truth-evaluation}

[Ground-truth evaluation](./model-testing/ground-truth-evaluation.md) specifies
scoring against isolated simulation truth and the interpretation of each metric.
