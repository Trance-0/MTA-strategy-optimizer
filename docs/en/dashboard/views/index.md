# Dashboard Views and Visual Contract

The dashboard presents governed pipeline evidence through shared navigation, forms, charts, and tables. Each topic below owns the reader-facing rules and source contracts for the components that implement it.

- [Key-Term Help](./term-help.md): Accessible term help, registry lookup and definition links for dashboard labels.
- [Deployment Capability Governs the Interface](./deployment-capability.md): Database mode controls editing, deployment accents and read-only remedies in dashboard views.
- [Canonical Entities Are Lists, Not Prose](./entity-lists.md): EntityTable paging, identity-keyed selection, draft editing and named archive confirmation.
- [Running a Stage from the Dashboard](./stage-execution.md): StageRunner model options, server phases, dataset selection, queued execution, and artifact transfer.
- [Reliability is never a footnote](./reliability.md): ReliabilityBanner visibly qualifies governed attribution and budget evidence.
- [Visual Contract](./visual-contract.md): Theme palettes, fixed entity colors, chart axes and paired readable values.
- [Deferred chart rendering](./chart-rendering.md): PlotlyChart loads on mount, coalesces replacement props, avoids deep watchers, cancels detached draws and displays errors.

The eight pages are listed on [Dashboard](/en/dashboard/index.md#the-eight-pages). This page specifies what they share beyond the question each one answers: the reliability rule every data view honors and the colour, chart, formatting, and key-term help system they draw from.


The [page behaviors](./page-behavior.md) specify each selected data view.
Contributor view contracts remain on the [existing views page](../views.md).
