# Historical Evidence and Lineage

These classes describe historical attribution without making an optimization claim and describe record provenance without coupling it to a local file path. See the [Canonical Data Model](../index.md) for the complete relationship diagram and source-file contracts.

## Class Index

- [Attribution Evidence](./attribution-evidence.md): one touchpoint's historical attributed share and value for one outcome.
- [Data Lineage](./data-lineage.md): the logical source, versions, timing classification, and synthetic-data status of a record.
