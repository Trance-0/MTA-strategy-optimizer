# Product Identity and Economics

These classes separate business-product identity from advertising identity, attach economic values without fabricating missing costs, and express Campaign-to-Product eligibility explicitly. See the [Canonical Data Model](../index.md) for the complete relationship diagram and source-file contracts.

## Class Index

- [Product](./product.md): provider-independent business-product identity.
- [Product Economics](./product-economics.md): price, cost, contribution margin, and margin provenance for a product.
- [Campaign Product Link](./campaign-product-link.md): the explicit many-to-many Campaign-to-Product relationship.
