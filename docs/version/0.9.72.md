# Version 0.9.72

Date: 2026-09-18

## Changes

- The tutorial now teaches by having the reader operate the application instead of reading descriptions beside it. A step is one of two kinds: an **action** step names a real control and is completed only when the reader clicks it, and a **note** step explains something with no button and is acknowledged.
- The mask now blocks input. Its four panels take pointer events, so during an action step the highlighted control is the only thing on the page that can be pressed. The overlay listens for that click in the capture phase without cancelling it, so the application's own handler still runs: one click both performs the operation and advances the step.
- Action steps perform real work — opening the Data source tab, **Reload data**, both stage **Run** buttons, and **Recompute strategy** all reach the server exactly as they do outside the tutorial. An action step offers no Continue button and the right arrow key will not skip it, because a walkthrough that advances past the thing it teaches has taught nothing. A step marked optional offers **Skip this step** only when its control is absent or disabled, so a read-only deployment is never trapped.
- The step card now measures its own height and takes the side of the highlight with room for it — below, else above, else pinned within the viewport — and animates between positions with the mask and ring.
- Added per-control anchors for the buttons action steps require: `settings-tab-source`, `reload-data`, `run-<stage>` on each stage runner, `model-tab-<key>` on each optimizer tab, and `optimizer-recompute`.
- Split the tutorial specification out of `navigation.md`, which had reached 510 lines, into `docs/en/dashboard/guided-tutorial.md`, and linked it from the dashboard index and the Settings section.

## Verification

190 dashboard tests passed, including a new one asserting that every step kind is known, that every action step names a control, that the overlay binds a non-cancelling capture-phase click listener, that no Continue button renders on an action step, and that the arrow key cannot skip one. The production build succeeded and the rebuilt Docker stack serves the blocking mask, the "Your turn" badge, the skip control, and the click listener. Both documentation pages are within the 500-line ceiling.
