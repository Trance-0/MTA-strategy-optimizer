# Version 0.9.64

Date: 2026-09-18

## Changes

- A supplied initial budget can initialize a selected Campaign with no own budget record. Provider and ad-product setup from the selector defines compatible touchpoint history; the selected Campaign remains the only allocation target.
- Historical fallback recommendations preserve the user-entered budget rather than adopting a donor budget. Missing own budget evidence is still rejected when no initial budget is supplied.
- Add a plotted marker for empirical historical recommendations. Fitted response plots continue to show observed points, fitted response, initial budget and optimized budget together.

## Verification

Eighteen backend model tests and 185 dashboard tests passed. The production dashboard build and Docker Compose stack passed. The Docker API returned KFC-AMAZON-DISPLAY with initial budget 520, 250 compatible observations and a 520 historical recommendation. No database records changed.
