# Version 0.9.42

Date: 2026-09-04

## Changes

- Added a separate Ontology Review subsection to Knowledge Base while preserving
  the mainline backend-knowledge unavailable state. It displays five canonical
  R5 budget-policy scenarios, their plan/release/rule identity, supplied verdict,
  policy values, evidence, limitations, availability, and next step without
  calling a Review API or recalculating a result.

- Tracked the upstream source manifest and five synthetic payloads as an
  immutable exact-six input. The importer rejects extra or linked files,
  validates complete field allow-lists, identities, relationships, byte sizes,
  SHA-256 digests, and prohibited public-data patterns, and can verify the
  pinned source/release Git relationship during a controlled refresh.

- Made development, normal production, and static builds use the same offline
  prepare command. Production and static outputs are revalidated, and Pages
  assembly revalidates the bundle again after its final copy. The review data
  loads only when its subsection is entered, has a bounded retryable timeout,
  and aborts on unmount. Loading, error, defensive empty, and ready states fail
  closed; deep links, keyboard navigation, and narrow layouts remain explicit.

- Hardened the import boundary by pinning the source manifest's raw bytes before
  parsing, requiring one canonical generated-manifest byte sequence, and
  rejecting output paths whose resolved `dashboard` or `public/data` ancestry
  escapes the project through a link or junction.

## Verification

- All 94 dashboard tests pass. The normal Vue production build completes and
  revalidates all five published fixtures. Canonical source and release commits
  resolve locally, the source is an ancestor of the release, and the tracked
  exact-six files match the release commit byte for byte.

- Static Vue, VitePress, final Pages assembly, documentation/source ownership,
  path safety, and final diff checks are completed before this patch is offered
  for commit. Public deployment and live smoke testing remain post-merge release
  gates rather than claims made by this local patch.
