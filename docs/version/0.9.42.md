# Version 0.9.42

Date: 2026-09-10

## Changes

- Added searchable Provider, Product, and Ad product checkbox groups with
  selected counts, draft/apply status, select-visible, clear, and reset actions.
  Filters combine alternatives within each group and require all selected groups.
- Preserved strict budget identities and corrected ad-product filtering, zero
  budget scoring, deterministic result ordering, result totals, and missing-data
  notices. Reset all clears the budget and searches and restores threshold 0.60.
- Loaded Campaign-product report rows when budget history is absent. The current
  report provides 34 rows, four Campaigns and four products. Its full periods and
  reported sales remain intact; spend is never substituted for missing budget.
  References stay presentation-only and never enter attribution or optimization.

  pass; frontend and documentation production builds complete successfully.
- Browser checks verify draft/apply, search selection and reset, including two
  report results for SKU_TRAIL_BLUE with AMAZON_DSP and unavailable budgets.
