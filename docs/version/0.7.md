# Version 0.7

Released: 2026-08-11

- Moved every concrete attribution model and the shared model interface into `mta_attribution`.
- Restricted `mta_standard` to loading, adaptation, model registration, execution, validation, and evaluation.
- Restored the strategy recommendation module as an independent owner of budget initialization.
- Added one-to-one implementation documentation and theme-aware Draw.io architecture diagrams.
- Preserved Chinese source documentation while publishing English pages only.
