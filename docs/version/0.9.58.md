# Version 0.9.58

Date: 2026-09-14

## Changes

- Retain 64 recently used loader results and serve expired buffers for ten additional minutes while up to four background refreshes build atomic replacements.
- Share concurrent cold loads and errors; retry failed refreshes after 30 seconds and prevent invalidated work from restoring an old buffer.

## Verification

All 194 backend tests passed, including four new cache cases; 18 snapshot tests also passed in Docker. The existing Compose stack built and became healthy with PostgreSQL enabled. Campaign History rendered 36,000 observations. Its 18.4 MB response took 2.19 seconds cold and 0.69 seconds on repeat.

Registered-dataset storage reported unavailable; legacy database resources succeeded. Buffers remain process-local and do not remove serialization or transfer costs.
