# Version 0.9.15

Date: 2026-08-18

## Changes

- Restructured the top nav bar in `docs/.vitepress/config.mts`: removed the "Home" item, since the site logo already links to `/en/`; moved "Dashboard" to the second position, right after "Overview"; and merged "Versions" and "Work Log" into a single "Logs" dropdown item with those two as sub-items, to save nav bar space.
- Renamed the "Datasets" documentation section to "Market Simulation" (nav label "Market Sim"), including `git mv` of the entire `docs/en/datasets/` directory to `docs/en/market-simulation/` (20 files: model pages, Draw.io sources, and light/dark SVG renders), the matching `docs/.vitepress/config.mts` sidebar scan block, and the section's `index.md` title and heading. Fixed roughly twenty live cross-reference links across `README.md`, `docs/en/attribution/`, `docs/en/dashboard/`, `docs/en/introduction/`, `docs/en/research/amazon/`, `docs/en/strategy-evaluation/`, `docs/en/strategy-recommendation/`, and `docs/worklog/`. Left the historical, backtick-quoted path mentions in already-published `docs/version/*.md` pages and all `docs/zh/**` sources untouched, consistent with the project's rule against rewriting historical narrative and preserved Chinese sources.
- Fixed `docs/version/0.9/` (and every future minor-version folder) not collapsing by default: the version-log sidebar scan block set `collapseFromLevel: 2`, but minor-version folders sit at scan depth 1, one level too shallow to reach that threshold, so `vitepress-sidebar` omitted the `collapsed` property entirely and rendered them always-expanded. Lowered `collapseFromLevel` to `1` in that one scan block.
- Loosened the work-log rule in `AGENTS.md`: an agent now compacts the current change set into today's working-log entry automatically while preparing a commit, instead of asking its owner and waiting for confirmation first. The entry is still written only on the agent's own owner's page, presented alongside the proposed commit message for review, and git commit execution itself still requires the owner's explicit request — only the extra pre-commit question about the work-log entry's content was removed.

## Verification

- `npm run build` in `docs/` completed with no dead links or scan errors after the rename and nav changes.
- Inspected the built `docs/.vitepress/dist/404.html` theme config JSON: the nav array reads `Overview, Dashboard, Market Sim, Attribution, Strat. Rec., Strat. Eval., Research, Logs` with no `Home` entry, and `Logs` carries `Versions` and `Work Log` as `items`.
- Inspected the same file's sidebar JSON for `/version/`: the `Version 0.9` folder entry carries `"collapsed":true`.
