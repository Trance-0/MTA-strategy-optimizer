# Version 0.9.3

Date: 2026-08-12

## Changes

- Made the Gitee mirror preserve its protected `master` branch as an exact alias of GitHub `main`, preventing Gitee from rejecting a protected-current-branch deletion.
- Force-updated every GitHub branch and tag on Gitee, pruned non-GitHub refs except the protected `master` alias, and added an exact object-ID verification gate.
- Added a textual progress bar to the live Actions log and a persistent progress table to the GitHub Actions run summary.
- Added the new strategy-evaluation framework, strategy-loader, and strategy-structure design documentation to the English site navigation.
- Moved the implementation specification catalog into the introduction section and corrected its campaign-hierarchy terminology.
- Updated workspace and project-structure links to the specification catalog's new location.
- Added the external user-interface design prototype supplied in the working tree.
- Consolidated historical versions 0.3 and 0.4 to keep no more than ten version-log pages.

## Verification

- Parse both GitHub Actions workflow files as YAML and syntax-check the mirror Bash scripts.
- Build the VitePress documentation using the GitHub Pages repository base path.
