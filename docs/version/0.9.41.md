# Version 0.9.41

Date: 2026-09-03

## Changes

- Made Campaign History display a transition immediately and consume backend
  progress phases over newline-delimited JSON streaming. The proxy disables
  buffering for the stream, and the database history resource avoids rebuilding
  unrelated research data before returning its result.

- Added one in-memory first-in, first-out backend task manager shared by model
  runs and schema operations. It records bounded logs, timestamps, progress,
  safe input summaries, and terminal state; callers can inspect every task,
  cancel queued work, or request termination of a running child process.

- Added `GET /api/tasks`, task-detail, and stop routes. Settings now presents
  database setup as Connect, Inspect, Import, and Verify, polls queued schema
  recovery work, and includes a Tasks tab with build-style logs, Copy log,
  Refresh, and Stop controls.

## Verification

- All 119 backend tests and 47 dashboard tests pass, including queue order,
  cancellation, task logs, streamed history progress, and schema-operation
  integration.

- Ruff checks and formats every changed Python file. Python compilation,
  production and static Vue builds, the VitePress build, Git whitespace checks,
  and documentation-length checks complete successfully. Live backend and
  browser smoke tests confirm the streamed endpoint and all three interfaces
  without console errors. Existing Plotly and VitePress bundle-size warnings
  remain unchanged.
