# Version 0.9.18

Date: 2026-08-18

## Changes

- Added a "## Documentation table usage" section to `AGENTS.md`: a Markdown table is permitted only as a strict side-by-side comparison of exactly two items across shared topics (column one names the topic, column two and three hold each item's value). Every other tabular use — component lists, field lists, definition lists, step lists, option lists — must be decomposed into sub-level headings instead, preferring `####` for definition lists. `docs/en/introduction/data-models/`'s pre-existing, stricter no-tables-at-all rule remains a narrower subset that still governs that directory.
- Fixed the specific violation flagged at `docs/en/dashboard/views.md`'s "The six view components" section: the six components were listed as table rows; each is now its own `####` heading.
- Audited every other Markdown file under `docs/en/`, `docs/version/`, and `docs/worklog/` for pipe-tables (`docs/zh/` was left untouched, as it is a preserved historical source excluded from site builds; `docs/en/introduction/data-models/` was left untouched, as it already had zero tables; `docs/en/strategy-evaluation/` was audited and then reverted, as it fell outside this change's scope). Found tables in 45 files; decomposed 135 of them into sub-level headings (heading level chosen as one level deeper than the section that governed the table, never skipping a level). 2 tables were genuine two-item comparisons and were kept — one was reshaped from 4 columns to the mandated 3-column form rather than discarded. No table content was summarized, translated, or dropped; every cell's information was relocated into the new heading's body.
- Fixed one stale `compact` frontmatter reference to a table that no longer exists (`docs/en/reference/module-inventory.md`, "One-table summary" -> "Summary").
- Rebumped every existing `docs/version/` `order` frontmatter value by 1 to make room for this page at `order: 1`, per the established single global descending-by-recency convention.

## Verification

- `npm run build` in `docs/` (VitePress) completes with no errors and no dead-link warnings after the full sweep.
- Spot-verified via repository-wide grep for pipe-table syntax (`^\s*\|.*\|.*\|\s*$`) that no unintended tables remain outside `docs/zh/`, `docs/en/strategy-evaluation/`, and the 2 kept comparison tables.
