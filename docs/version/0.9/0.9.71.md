# Version 0.9.71

Date: 2026-09-18

## Changes

- The tutorial now highlights the actual element each step teaches instead of describing where to find it. A step names a `target`, the overlay locates that `data-tour` element, scrolls it into view when it sits outside the comfortable viewport band, and cuts it out of the dimming mask.
- The mask is four opaque panels drawn around the element rather than one translucent sheet over it, so the highlighted control keeps its own colours, focus ring, and hover states and stays clickable while the step explains it. A pulsing ring traces the cutout, and both the panels and the ring animate between positions so advancing reads as the spotlight travelling rather than the page flickering.
- The step card is anchored beside its highlight, flipping above or below depending on which side has room, so it never covers the thing it points at. A step with no target dims the whole page, which is what a step introducing a page rather than a control wants.
- Added `data-tour` anchors to the elements the lessons teach: the top bar's dataset selector, the Settings tab strip, the database doctor and active-source group, both stage runners, and the Campaign Optimizer's model tabs, campaign card, history-source row, budget rows, Recompute action, reliability banner, disagreement chart, recommended-attribution table, response curve, and touchpoint budget plan.
- Rewrote the three sections around those anchors, so each step points at one control rather than summarizing a page. The optimization section now walks the selector, the history source, the budget fields, the Recompute button, the curve, and the touchpoint split as separate highlighted steps.

## Verification

189 dashboard tests passed, including a new assertion that every `target` named by a step exists as a `data-tour` attribute in a component, so a step cannot point at nothing, plus assertions for the mask, ring, scroll, and transition behavior. The production build succeeded and the rebuilt Docker stack serves the mask, ring, pulse keyframes, and anchored-card rules, with all ten optimizer anchors present in the served chunk.
