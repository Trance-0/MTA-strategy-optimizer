# Version 0.9.20

Date: 2026-08-18

## Changes

- Integrated Multi-Touch Attribution Simulator (MTA-SIM) through a stable file boundary while keeping it independently runnable. The simulator now owns provider-independent domain dataclasses, native five-segment impression/click generation, explicit Provider visibility profiles, configurable Products, Campaigns, Ad Groups, granular product economics, budget experiments, diminishing returns, and organic versus incremental outcomes. Existing configurations and the three established Comma-Separated Values (CSV) schemas remain compatible.
- Added `modules/mta_standard/src/mta_sim_research_adapter.py` to construct the existing `mta_common` Provider, Touchpoint, Product, Campaign, budget, delivery, outcome, scope, and lineage objects from simulator sidecars. Native five-segment data is now the normal loading path; historical four-segment data retains only its explicit compatibility mapping.
- Added deterministic research profiles for 10,000 local observations and direct batched persistence of 100,000 observations to resettable PostgreSQL tables. The live database contains 100,000 budget and evaluation observations, 40 Campaigns, 40 Ad Groups, and no orphan Campaign relationships.
- Reorganized Budget Manager into progressive Provider, Product, Campaign, Ad Group, Touchpoint, Product Economics, and Generation Config sections. Database edits create future-run drafts without mutating generated history; local mode reads the simulator's unchanged CSV files and research sidecar.
- Expanded Campaigns into a historical explorer with Provider/Product/Campaign/run/date filters, budget-versus-spend and interaction-aware performance, path statistics, existing attribution display, and a thresholded presentation-only similarity reference that cannot feed attribution or strategy optimization.
- Centralized remaining touchpoint parsing in canonical adapters and removed superseded manual parsers, unused imports, and obsolete four-segment assumptions from current-data paths.

## Verification

- Passed 27 MTA-SIM baseline tests, 6 regional tests, 103 `mta_common` tests, 98 `mta_standard` tests, 160 attribution tests, 34 strategy tests, and 31 dashboard tests: 459 automated tests in total.
- Two independent 10k runs produced byte-identical outputs; all performance and path touchpoints were five-segment values, with ordered impression-to-click paths preserved.
- Direct PostgreSQL generation used batches of 1,000 and produced 100,000 budget observations, 100,000 evaluation outcomes, 7,000 delivery observations, 7,000 ordinary outcomes, 7,000 performance rows, 3,500 paths, and 7,171 ground-truth rows.
- The dashboard queried the final database schema, draft save/archive left all 100,000 historical observations unchanged, all eight research indexes were present, and referential-integrity probes found zero orphan Ad Groups, Campaign-Product links, or budgets.
- Both documentation sites and the dashboard production bundle built successfully; Python compilation, source linting, and `git diff --check` passed.
