# Version 0.9.70

Date: 2026-09-18

## Changes

- Fixed the tutorial being invisible. It was rendered inside `Settings.vue`, so the component was unmounted the moment its first step navigated away from Settings and the walkthrough disappeared with it. State now lives in `dashboard/src/lib/useTutorial.js` and the overlay is rendered once by `App.vue`, outside every routed view, so a lesson survives every navigation it performs. `TutorialLauncher.vue` contributes only the Settings row.
- Replaced the single fixed sequence with three independently selectable sections: **Set up a data source**, **Run the attribution model**, and **Run the optimization model**. Opening the tutorial presents a picker, finishing a section records it and returns to the picker, and **All sections** leaves a section without finishing it. A reader who wants attribution no longer has to walk database setup first.
- Gave the tutorial the overlay it was specified to have: a grey veil over the application, and a bar across the top carrying the section name, the step count, a segmented progress strip, and the **All sections** and **Quit tutorial** controls. The veil sets `pointer-events: none`, so it dims the page without blocking the control a step points at.
- The data-source section uses the synthetic KFC scenario as its example and says so, since any valid schema behaves the same way; the lesson does not depend on that scenario being present.

## Verification

188 dashboard tests passed, with the tutorial assertions rewritten to read the new state module, require at least twelve routed steps across the three sections, and confirm the overlay markup and the Settings launcher. All sixteen steps resolve to registered pages and subsections. The production build succeeded and the rebuilt Docker stack serves the overlay, the three section titles, and the tutorial rules from the main bundle rather than the lazy Settings chunk.
