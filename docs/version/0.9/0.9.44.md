# Version 0.9.44

Date: 2026-09-05

## Changes

- Kept the repository root as the Dashboard image build context and added the
  one tracked Willow demonstration JSON required by the existing static import.

- Tightened the Docker ignore exceptions at every parent directory, so the
  image build can traverse to that JSON without admitting the rest of
  `docs/`.

- Added a Dashboard regression check for both external build inputs: the
  canonical Ontology Review importer and the Willow demonstration model.

This patch changes build wiring only. It does not change the JSON bytes, the
Willow component, canonical R5 fixtures, backend behavior, model code,
strategy algorithms, or evaluation algorithms.

## Verification

- Dashboard tests and the normal Vue production build pass.
- The release Docker build is the authoritative check that the clean context
  contains every allow-listed input.
