# Version 0.9.66

Date: 2026-09-18

## Changes

- Added `config/mta_sim/kfc-global.json`: the merged single-scope KFC scenario (marketplace `GLOBAL`, USD, all six campaigns) with a nine-level randomized budget experiment, giving every Campaign dense budget-response support where the three regional schemes observe only three scheduled levels. Documented the scenario family on the generation page.
- Moved the analysis dataset selector from a card above every view into the top bar as one compact row — select, Refresh, Import, and a Details popover for scope, capabilities, and provenance — and kept it visible on narrow viewports where the header tags give way.
- Added the Touchpoint budget plan panel to the optimizer tab: the decided Campaign daily budget divided across the Campaign's own touchpoints by recommended attributed credit, with reliability verdicts and an explicit indicative-only warning; the optimization route now also loads the attribution resource.
- Fixed `_campaign_history_dataset` in `backend/services/models.py`: a null-budget-level ordinary outcome now joins its day's single active budget arm at any level (multi-arm days keep the baseline-only match), and simulator provider profiles outside the canonical vocabulary map lossily to `GENERIC` instead of raising `ValueError`.

## Verification

203 backend tests and 185 dashboard tests passed; the production dashboard build succeeded. A local Docker PostgreSQL preview exported the generated `kfc-global` run, derived the `mta_kfc_global` dashboard schema, and returned `is_optimized: true` with 365 observations and `TARGET_HISTORY` support for KFC-GOOGLE-SEARCH, KFC-AMAZON-DISPLAY, and KFC-META-FEED. No remote database was written.
