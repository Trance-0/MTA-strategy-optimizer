# Version 0.9.8

Date: 2026-08-14

## Changes

- Updated `.github/workflows/mirror-to-gitea.yml` so `GITEA_REPOSITORY` accepts a credential-free `https://host/owner/repository.git` address for any Gitea service. The `owner/repository.git` shorthand still resolves to `https://gitea.com`.
- Passed the validated base address and repository path separately to the mirror step and removed the hard-coded `gitea.com` push destination. Credentials remain supplied only by the existing askpass helper.
- Documented the accepted secret forms, rejection rules, synchronization triggers, protected `master` alias, and exact reference verification in the English environment specification.
- Consolidated versions 0.1 through 0.8 into one archive page to preserve the ten-page version-log limit.

## Verification

- Parsed `.github/workflows/mirror-to-gitea.yml` with the documentation workspace's YAML parser.
- Executed the workflow's configuration script against five cases: the configured self-hosted address and the gitea.com shorthand passed with the expected normalized outputs; plain HTTP, embedded credentials, and nested paths failed.
- Confirmed the configured self-hosted Gitea service responds over HTTPS before publishing the workflow change.
