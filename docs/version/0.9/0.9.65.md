# Version 0.9.65

Date: 2026-09-18

## Changes

- The generator-report adapter in `modules/mta_standard/src/mta_sim_generator_adapter.py` now validates path and performance CSV headers against the canonical field tuples and rejects rows missing required scope fields with a bounded `ValueError` naming the row and fields, instead of leaking a raw `KeyError`.
- Strategy projection in `modules/mta_strategy_evaluation/src/strategy_projection.py` reports missing `campaign_id` and `ad_group_slot_id` values as `StrategyProjectionError`, reconciles the six-decimal serialization share residual onto the final Campaign allocation so conservation stays exact, and reports missing or unreadable artifacts by artifact name without private paths.
- Recorded the from-scratch integration check — generation, registered-dataset upload, attribution, optimization, and evaluation — on the generation and evaluation pages, including the toy-scope optimizer refusal and the single-marketplace optimized run.

## Verification

All 581 module tests and 203 backend tests passed. The full generate → upload → attribute → optimize → evaluate flow completed from empty state on a single-marketplace research profile: one projected and conserved optimizer strategy, the deterministic seed correctly reported as not run, and attribution comparison outputs published. Adapter changes only; no model mathematics changed.
