# Version 0.9.1

Date: 2026-08-12

## Changes

- Made the documentation-root redirect and site-title link aware of the deployed site root, so GitHub Pages sends readers to `/MTA-strategy-optimizer/en/` while local previews continue to use `/en/`.
- Allowed `GITEE_REPOSITORY` to use either an HTTPS `gitee.com` repository URL or the shorter `owner/repository.git` form, without allowing embedded credentials.
- Defined version ownership: project managers control major versions, human developers control minor versions, and agents increment only patch versions unless explicitly directed otherwise.

## Verification

- Build the VitePress site with `DOCS_BASE_PATH=/MTA-strategy-optimizer/` and inspect the generated root redirect.
- Validate the GitHub Actions workflow syntax and exercise repository-target normalization with the configured HTTPS URL shape.
