# Version 0.9.39

Date: 2026-09-02

## Changes

- Changed dashboard-started schema initialization and derivation to invoke
  `script/import_to_database.py` and `script/derive_scenario_schemas.py` with
  the backend's active `sys.executable`. The deployed environment already has
  the locked backend dependencies, so schema setup no longer fails before
  Python starts when `uv` is absent from the executable path.

- Preserved the fixed, shell-free argument vector and every existing schema
  census, replacement, logging, termination, and cache-invalidation safeguard.
  Regression assertions cover the interpreter prefix for both actions.

## Verification

- The importer dry-run completed for `mta_asia` through the active interpreter
  without opening a database connection.

- All 104 backend tests pass. The documentation production build and Git
  whitespace inspection complete successfully.
