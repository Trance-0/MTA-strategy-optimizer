# Version 0.9.63

Date: 2026-09-18

## Changes

- Use one native input with datalist suggestions, matching Campaign identifiers and labels as the reader types. Only an exact identifier or unique exact name becomes an allocation target.
- Keep optimizer settings visible during partial, empty and unmatched input. Show inline feedback and preserve numeric values until a new target is selected.

All 184 dashboard tests passed, including the explicit uni / unixxxx / United States interaction and the absence of requests for partial text. The existing Docker stack built successfully and became healthy. Browser interaction was not independently verified in this patch.
