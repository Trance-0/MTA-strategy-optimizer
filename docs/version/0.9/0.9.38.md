# Version 0.9.38

Date: 2026-09-02

## Changes

- Preserved the real baseline toy generation test when the pinned MTA-SIM
  checkout exists, but made that single integration case skip explicitly in
  the container-publishing workflow's deliberate source-only checkout. The
  configuration path and workload limits now use a self-contained synthetic
  request fixture and remain active without external source.

- Strengthened generator availability to require the simulation package and
  every allow-listed preset file. A missing or incomplete checkout remains a
  successful overview capability response with `available: false`, a bounded
  reason, and no configuration.

- Converted a known preset request with unavailable pinned source into `503
  generator_unavailable`. The response no longer becomes Flask's unhandled 500
  and never exposes the runner's absolute checkout path. Unknown preset pairs
  continue to return 404.

## Verification

- The Data Generator tests pass with the initialized simulator checkout and in
  a forced missing-submodule process; the latter reports exactly one skipped
  real integration case while all seven hermetic tests pass.

- The full backend suite, changed-file Ruff checks, Python compilation,
  documentation build, and Git whitespace inspection complete successfully.
