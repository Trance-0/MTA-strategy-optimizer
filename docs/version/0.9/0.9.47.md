# Version 0.9.47

Date: 2026-09-07

## Changes

- Removed the entire tracked root `script/` directory and ignored `/script/`
  and `/scripts/`. Removed inspection/preflight helpers and their dedicated
  tests. Existing model commands now run through their owning Python packages;
  database import, derivation and static export live in `backend/`.
- Repaired runtime subprocess arguments, imports, tests, interface instructions,
  package commands and Docker inputs. Dashboard fixture preparation lives in
  `dashboard/build/`; documentation integrations live in `docs/.vitepress/`.
  Configuration and build modules remain trackable; only caches and build
  output are ignored. English specifications describe the new entry points.
- Kept mirror operations inline in the existing GitHub workflow. Prepare and
  verify the pinned submodule snapshot before one atomic branch/tag publication.
  Gitea `main` receives the generated child commit, with an optional `master`
  alias. Other references mirror GitHub exactly; destination-only refs are pruned.
- Documented owner-run GitHub Actions and changes to the existing Yunxiao job:
  clone materialized `main` without recursion, retain parent history, check
  source before `rsync`, preserve generated data, and keep required dependency
  extras installed. The complete existing pipeline configuration lives in
  `deploy/yunxiao/pipeline.yaml`, with every deployment command inline in
  `run: |`; there are no additional deployment scripts or wrappers.
- Added repository rules requiring the fewest files a task allows, one file per
  deliverable when the format can carry it, no markdown outside `docs/` except
  the root readme, and commented functional code in maintained scripts.
  Consolidated `deploy/yunxiao/` accordingly: its shell script and readme were
  removed, their operating steps and prerequisites became header comments in
  `pipeline.yaml`, and its six inline stages gained the reasoning comments the
  new rule requires.
- Assigned this change set version 0.9.47 after 0.9.46 was taken by the merged
  Data Generator release, and archived 0.9.43 into `docs/version/0.9/` to keep
  the four most recent patches flat. Added Chenghao Jin to the work-log roster
  as the owner of the Data Generator configuration workflow, and corrected the
  roster's pipeline area, which still named the removed `script/` directory.
