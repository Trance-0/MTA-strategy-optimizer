# Version 0.9.25

Date: 2026-08-20

## Changes

- Added a pipeline architecture diagram (`docs/en/mta-optimizer-pipeline.drawio`, rendered as light and dark SVG) describing the flow from New Campaign and Data Collection through MTA Calculation, Campaign Strategy Recommendation, Performance Prediction, A/B Testing, Operational Data Collection, and ROI Calculation and Reporting.
- Swapped it in for VitePress's default circular hero image on the English documentation homepage only: a new `docs/.vitepress/theme/Layout.vue` wraps `DefaultTheme.Layout` and fills the `#home-hero-image` slot with the existing `DrawioDiagram` component when the current page is `en/index.md`, registered by importing `Layout` into `theme/index.ts`'s `enhanceApp` export. Every other page, including the (untranslated) root and Chinese homepages, keeps the default hero.
- Added hero-specific overrides in `custom.css`: `VPHero`'s decorative blurred circle and fixed square image sizing are disabled, since that styling was designed for a small circular logo rather than a flow diagram, and above `960px` the hero text and image are reordered so the diagram sits to the left of the text at up to full width instead of the default's smaller right-aligned image.

## Verification

- `npm run build` in `docs/` succeeds; confirmed `mta-optimizer-pipeline.drawio`, its light and dark SVG, and the rendered `drawio-diagram` markup all land under `docs/.vitepress/dist/en/`.

## Notes

- This diagram and its theme integration were authored in the same earlier, uncommitted working session as [0.9.24](0.9.24.md)'s deploy restructuring; reviewed and verified here before commit.
