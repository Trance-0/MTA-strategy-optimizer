# Versions 0.1–0.4

Released: 2026-07-16 to 2026-07-30

This page consolidates four early versions so the version log retains at most ten pages. It preserves the material changes of each version; the original per-version narratives are not otherwise required by current contracts.

## Version 0.1

- Cleaned and organized the repository workspace.
- Established Amazon Marketing Cloud (AMC) Multi-Touch Attribution (MTA) as the active implementation focus.
- Added workspace inventory, architecture, and capability documentation.
- Restored reproducible synthetic event samples and audited the initial inputs, outputs, and tests.

## Version 0.2

- Reduced the governed attribution output set to five canonical files.
- Simplified reliability checks and comparison outputs.
- Expanded the synthetic attribution sample and added reporting-window detection.
- Added reliability-aware recommended attribution values.
- Prepared the AMC MTA submission documentation and formal data-flow diagrams.
- Normalized whitespace at Comma-Separated Values (CSV) input boundaries.

## Version 0.3

- Added the initial Multi-Touch Attribution-informed campaign strategy initializer.
- Connected historical attribution evidence to the planned Ad Group budget stage.
- Documented the boundary between historical attribution, performance prediction, and future constrained optimization.

## Version 0.4

- Unified synthetic event generation across attribution inputs.
- Simplified the strategy data contract and aligned recommendations with Amazon Marketing Cloud evidence.
- Added Multi-Touch Attribution-driven initial budgets at Ad Group level.
- Organized budget-model artifacts and clarified which materials are historical.
