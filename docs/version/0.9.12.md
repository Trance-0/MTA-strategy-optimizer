# Version 0.9.12

Date: 2026-08-17

## Changes

- Split `docs/en/dashboard/index.md` — previously a single 399-line page — into five pages: `index.md` (architecture, the dual data source contract, and the six-view table), `views.md` (the reliability rule and the visual contract), `navigation.md` (the rail and its settings module), `deployment.md` (the local launchers and the GitHub Pages static build), and `database-import.md` (the PostgreSQL schema and importer). Each new page carries its own `compact`, `source_files`, and `## Source Files` section, and cross-links back to `index.md` and to each other; the `dashboard/index.md#two-data-sources-one-contract` anchor referenced from `docs/en/datasets/dashboard-data-model.md` was kept in place and unrenamed.
- Fixed the abbreviation-expansion rule at each new file's first occurrence of a term already expanded elsewhere in the original page: Structured Query Language (SQL) in `views.md`, Application Programming Interface (API), JavaScript Object Notation (JSON), Comma-Separated Values (CSV), and Uniform Resource Locator (URL) in `deployment.md`, and JSON in `database-import.md`.

## Verification

- `npm run build` in `docs/` completed with no dead-link, missing-file, or sidebar-scan error, confirming the four new dashboard pages register correctly and the `dashboard-data-model.md` anchor link still resolves.
