# Version 0.9.19

Date: 2026-08-18

## Changes

- Reorganized the 26 canonical class pages under `docs/en/introduction/data-models/` into eight subsection folders matching the overview's Class Index: vocabularies; touchpoint and provider contract; campaign identity; product identity and economics; budget, delivery, and outcome observations; historical evidence and lineage; composed episodes and evaluation isolation; and presentation-only similarity. Added one compact-frontmatter routing page per subsection.
- Enabled frontmatter ordering for the Introduction sidebar and assigned subsection and class-page orders so navigation follows the Class Index rather than alphabetical folder names. Updated every affected intra-model link and the Margin Source definition link to the new canonical paths.
- Added `canonical-data-model-relationships.drawio` beside the owning overview and rendered its light and dark Scalable Vector Graphics (SVG) variants. The diagram places all 26 terms into six vertical topological tiers, writes ordinary typed dependencies inside consumer boxes, and reserves its six orange arrows for foreign-key-style `campaign_id` and `product_id` relationships only.
- Added a published follow-up remark to revisit the class-index dependency diagram after the canonical classes are adopted by the attribution, strategy, evaluation, and dashboard runtime paths.
- Rebumped the existing top-level version-menu `order` values by 1 so this page is the unique newest entry at `order: 1`.
