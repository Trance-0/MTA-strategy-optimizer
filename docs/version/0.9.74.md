# Version 0.9.74

Date: 2026-09-24

## Changes

- Replaced Gitee raw branch and tag copying with the Gitea snapshot sequence: import pinned first-level submodule trees, remove nested Git links and root `.gitmodules`, validate generator inputs, and publish only the default branch and its `master` alias.
- Retained Gitee destination validation and existing GitHub secrets; disabled proxies for Gitee transport and adopted bounded transport retries, atomic publication, and exact reference verification.
- Updated the owning mirror specification to require equal file trees for equal GitHub inputs while allowing destination-specific snapshot provenance. Moved the oldest flat patch page into its historical minor-version folder.

## Verification

Both workflow bodies passed Bash syntax checks and ran against disposable repositories. Their root tree identifiers matched; tracked ignored files survived, nested links disappeared, stale branches and tags were pruned, and unchanged inputs produced stable snapshots. Invalid generator configuration preserved both destination reference sets.
