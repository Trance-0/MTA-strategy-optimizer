# Version 0.9.61

Date: 2026-09-18

## Changes

- Load the Campaign catalogue on the optimizer route and add a native searchable selector matching identifier, name, provider and ad product. The selected Campaign remains the sole allocation target.
- Add smart matching controls alongside the existing history source, initial budget and similarity threshold. Changing the target clears its initial budget and invalidates in-flight results; changing the dataset clears the target and source context.
- Include selector and matching inputs in the documented route contract and keep native controls keyboard accessible.

## Verification

The rebuilt Docker stack became healthy. The catalogue endpoint exposed 40 Campaign choices; Docker API checks returned the requested initial budget and threshold for multiple Campaigns, and exact threshold filtering correctly refused when no reference matched. Seventeen backend model tests and 183 dashboard tests passed.
