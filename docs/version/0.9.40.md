# Version 0.9.40

Date: 2026-09-02

## Changes

- Added a General Settings tab containing deployment identity only. Data source
  and Logging no longer repeat it. Logging now starts at INFO and follows the
  public Notechondria operator pattern with structured UTC timestamps, optional
  durations, severity/source display filters, copy, clear, and a bounded
  in-memory ring.

- Fixed model execution without `PIPELINE_OUTPUT_DIR` by creating and
  write-probing the ignored `generated/pipeline-output` runtime. A Python
  backend in file mode can run against fixed server-owned inputs; a static
  build still disables Run, upload, and import because no backend exists.

- Added fixed-manifest model artifact upload and download endpoints. The
  backend bounds and parses complete CSV or JSON sets before publishing them;
  database mode adds explicit transactional import into the optional
  `model_artifact` table and restores imported outputs for display and later
  pipeline stages after runtime loss.

## Verification

- All 114 backend tests and 47 dashboard tests pass, including exact filenames,
  malformed/path-like upload refusal, runtime fallback, database persistence,
  restoration, multipart upload/download, and file-mode import refusal.

- Ruff checks the changed Python files. Production Vue, static Vue, and
  VitePress builds complete; Git whitespace and documentation-length checks
  pass.
