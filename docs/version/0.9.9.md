# Version 0.9.9

Date: 2026-08-14

## Changes

- Fixed the published dashboard, which showed its own stylesheet as literal text for roughly twenty seconds of every cold load. The boot splash was removed as soon as Streamlit's app container appeared, but that container mounts when the runtime starts — well before the script it runs emits anything. Lifting the splash then revealed the interval in which the app's CSS block sits in the DOM without having been applied.
- `web/index.html` now waits for the navigation rail, which is the first thing `app.py` draws, so the splash lifts on evidence that the Python actually ran rather than on evidence that the runtime started.

## Verification

- Sampled the page every 250 ms from navigation to first paint, counting frames in which the splash was gone and the rail had not yet rendered. Watching the app container produced 373 such frames across a 95.7-second boot; watching the rail produced none across a 34.7-second boot.
- Confirmed on the deployed site that the dashboard reaches its full rendered state — rail, nine buttons, five metric tiles, four Plotly traces, and both outbound links — before the change, so the defect was one of what the visitor sees while waiting rather than of what finally loads.
