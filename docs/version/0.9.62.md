# Version 0.9.62

Date: 2026-09-18

## Changes

- Validate the Find Campaign field as it changes. Matching Campaign options remain in the selector; an unknown typed value sets the native invalid state and shows the typed value in an alert.
- Clear stale optimizer results and cancel in-flight display updates when the search changes. Prevent model requests while the Campaign search is invalid.
- Keep the loading state distinct from an empty catalogue and preserve keyboard-accessible native controls.

## Verification

All 183 dashboard tests passed, including matching, unknown-search, stale-result and target-change cases. The production dashboard build completed successfully. No database records changed.
