# Version 0.9.5

Date: 2026-08-13

## Changes

### Log separation

- Renamed `docs/logs/` to `docs/version/`, so the folder name states what it holds: one small patch description per project version. Updated the sidebar, navigation, README, and the version-governance rules accordingly.
- Added `docs/worklog/` to record general project progress by person, and gave it its own navigation entry. Version pages answer what changed; work-log pages answer who did the work and when.

### Contributor roster

- Added `docs/worklog/index.md` recording everyone involved, their handle, their area of responsibility, and their active period, with a second table mapping each area to the modules and documentation it lands in.
- Moved the repository-root `log.md` to `docs/worklog/JiahaoYao.md`, preserving the author's original Chinese text without translation, and added frontmatter so it publishes with the rest of the section.
- Removed `docs/en/introduction/development-history.md`. It was an English retelling of that same log; the per-person page is now the single record, and the narrative history it duplicated already lives in the version pages.
- Added per-person pages for Zheyuan Wu, Tianle Chen, Yi Liu, and Yayu Yu. The three pages with no recorded history carry their scope and an entry template rather than invented activity.
- Reconstructed Zheyuan Wu's development log from Git history, covering 2026-08-03 through 2026-08-12.

### Work-log rules

- Recorded the work-log scheme in the repository instructions: one page per person named in PascalCase, reverse-chronological `## YYYY-MM-DD` sections, and **at most three bullet points per section**.
- Recorded that a work-log page belongs to its owner. Agents must not edit another person's page, restructure past entries, or translate a page written in another language.
- Required that **before creating a commit, an agent asks its owner whether to compact the current change set into today's working-log entry**, proposes the exact text, and waits for explicit confirmation. Declining is valid and the commit proceeds without a work-log change.
- Replaced the former root `log.md` protection rule with a work-log ownership rule covering the whole `docs/worklog/` directory.

### Version-log maintenance

- Consolidated versions 0.5 and 0.6 into one archived page to stay within the ten-page version-log limit.

## Verification

- `npm run build` in `docs/` completes with no dead links after the directory rename, the section addition, and the removal of the development-history page.
- The three module test suites remain unaffected by this documentation-only change and continue to pass at 284 tests total.
