# Version 0.9.59

Date: 2026-09-14

## Changes

- Campaign history and catalogue entries open a source-preserving optimizer preview for the selected Campaign and marketplace. The backend fits ordinary daily budget, spend and revenue observations with the existing response model and constrained solver; automatic previews stay within the largest observed budget.
- Reject missing evidence, changed sources, invalid observations, inactive Campaigns and mixed reporting scopes. Evaluation-only outcomes and similarity scores never enter fitting; late responses cannot replace another source's result.
- Add Gower and strict profile-radius grouping, a validated numeric similarity threshold, and accessible grouping and optimizer tooltips. Shared entity tables expose an optional row action slot.

## Verification

- All 198 backend and 179 dashboard tests passed. The dashboard and documentation built successfully; 35 targeted backend tests passed inside the rebuilt Docker container.
- The PostgreSQL Docker stack became healthy. Browser checks verified Campaign links, automatic calculation, grouping selection, tooltip descriptions and invalid-threshold feedback.
- A real fitter test produces a single-Campaign strategy from five valid ordinary observations. The configured database currently has no matching ordinary outcomes for its varied-budget arms, so the live preview explicitly refuses instead of using evaluation-only outcomes. Registered dataset storage also reports unavailable in this environment.
