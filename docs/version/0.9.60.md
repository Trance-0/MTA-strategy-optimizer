# Version 0.9.60

Date: 2026-09-15

## Changes

- Match ordinary outcomes with no budget level to the baseline only; filter unmatched or invalid observations without discarding usable history. Keep account, currency, marketplace and run boundaries in observation joins.
- Default Campaign previews to the full compatible dataset, with a This Campaign only option. Fit transferable evidence when sufficient variation exists and preserve donor identity in response diagnostics and tables.
- Return an explicit Historical baseline recommendation when valid evidence has insufficient budget variation. Show its recommended observed budget and mean observed results without claiming fitted optimality or predicted uplift.

## Verification

All 201 backend tests and 181 dashboard tests passed. The dashboard production build and existing Docker Compose stack succeeded. All 16 model endpoint tests passed in the container.

All 80 campaign-marketplace combinations in the configured PostgreSQL database returned successful historical baseline recommendations, both through direct service calls and the Docker dashboard API proxy. For default_campaign_10_1 in CA, 250 comparable records support a CAD 100 baseline. A separate valid varied-budget fixture verifies a fitted transferred strategy.

Browser automation was unavailable because the browser connection could not authenticate; UI behavior was checked by reactive component tests and build validation, with HTTP checks through Docker. No database data was changed.
