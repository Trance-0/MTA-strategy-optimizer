# Version 0.9.48

Date: 2026-09-08

## Changes

- Added persistent, immutable datasets from generator output, standard
  Comma-Separated Values (CSV) and JavaScript Object Notation (JSON) files,
  and the standard Application Programming Interface (API). Validation previews
  identify scope and supported model stages; explicit selection drives analysis.
- Made trends, rankings, filters, detail views, distribution plots and downloads
  follow selected observations. Day, week and month summaries recompute ratios;
  monetary units, missing values, measured zero and fitted support remain explicit.
- Added named budget plans with immutable revisions and preserved drafts, plus
  isolated attribution and optimization runs with frozen inputs, queue state,
  cancellation, retries, logs and verified downloadable artifacts.
- Added formal evaluation of an exact successful optimization, clear unavailable
  evidence, paginated history and restart recovery. Capability messages distinguish
  readable data, writable storage and executable models; static views refuse writes.
- Completed the approved BMad requirements, design, architecture, implementation
  stories and code review under the English Dashboard specification. Archived
  the unchanged 0.9.44 page to retain four recent flat version pages.

## Verification

- Release verification passed all six Python suites (765 tests) and the
  frontend suite (168 tests). Connected and static Dashboard builds and the
  English documentation build passed.
- Actual local browser flows covered generator and file imports, source switching,
  saved budget revisions, native optimization and matching evaluation, artifact
  downloads and restart retention.
- Browser acceptance covered 100,000 imported observations, a 375-pixel viewport
  and native Safari 200-percent zoom. See the detailed
  [verification record](../en/dashboard/release_plan/verification.md).

## Limits

The import interface accepts the documented standard contract; direct external
advertising-platform connectors are not included. Model availability depends
on each dataset's inputs and support. Predictions remain estimates. The existing
large plotting-bundle build warning remains.
