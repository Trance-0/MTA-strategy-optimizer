# Version 0.9.75

Date: 2026-09-24

## Changes

- Restored the documented canonical review view in `dashboard/src/views/KnowledgeBase.vue`. The route again loads five checksum-verified fixtures lazily, supports retry and cancellation, labels synthetic data, and shows the supplied verdict and next step without inference.
- Removed the endpoint-driven pipeline from the active Knowledge Base route. The existing tests were detecting lost behavior, not merely renamed strings: the replacement bypassed the verified fixture adapter and attempted endpoint requests with mock fallback.
- Clarified the owning specification to prohibit endpoint-driven or unverified fallback review data in the production route. Existing deployment test gates remain intact.

## Verification

All 191 dashboard tests passed after reproducing the two failures. The production build succeeded and verified all five published fixture payloads. Rebuilt the existing Docker Compose stack with `deploy/docker/run.sh`; both services became healthy using database mode from the private root environment file.

Inspected Ontology Review and Data sources in the local browser. The five canonical options loaded, the conflict case required human authorization, the missing-policy case displayed insufficient evidence, and Data sources reported database mode. No browser console errors were recorded. Remote deployment still requires the owner to run the existing cloud pipeline after mirror publication.
