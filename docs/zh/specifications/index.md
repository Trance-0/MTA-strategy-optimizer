# 实现规格源文件索引

本目录保留项目历史实现规格的中文源文件，供项目定稿后恢复和完善中文站点时使用。

- `source/` 是 `_bmad-output/implementation-artifacts/` 的完整只读镜像。
- 英文站点中的当前分类入口位于 `docs/en/specifications/index.md`。
- 这些规格记录当时的意图、边界、验收标准和验证结果；当前代码、测试和数据契约具有更高权威性。
- 中文详细页面目前不发布，也不应从英文站点导航直接暴露。

原始 `_bmad-output` 文件继续保留，没有删除或覆盖任何历史描述。
