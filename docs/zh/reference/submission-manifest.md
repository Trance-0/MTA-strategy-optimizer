# AMC MTA 提交清单

`amc_mta/` 是唯一核心提交物。解压后以该目录为工作目录。下列边界用于代码审阅、演示和归档，不改变
任何运行路径或 CSV 契约。

## 必交：核心包

- `README.md`、`SUBMISSION_MANIFEST.md`；
- `src/`、`scripts/`、`run_pipeline.py`、`config.py`；
- `tests/`；
- `docs/`（包含完整使用说明和正式输出索引）；
- `docs/assets/amc-mta-data-flow.png` 及其可编辑 SVG 源文件；
- `data/simulated/` 的演示输入及说明；
- `outputs/attribution/` 的五份正式展示结果。

## 不包含：项目外部材料

- 原项目的 `docs/`：项目知识、背景研究和管理规则；
- 原项目的 `design-artifacts/`：明确标记为未实现的历史产品愿景。

这些材料不随独立包提交，不是运行依赖，也不得覆盖模块契约。

## 不随核心包提交

- 原项目的 `_bmad-output/`：工作流规格、实现状态和延期事项；
- 原项目的 `.agents/`、`_bmad/`：本地安装型开发工具；
- 个人环境覆盖、缓存和临时文件。
