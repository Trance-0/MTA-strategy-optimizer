# MTA 研究阅读顺序

本目录保存 MTA 方法论文和学习笔记，不是当前模块的运行输入。建议依次阅读：

1. [Data-driven Multi-touch Attribution Models](/research/mta/Data-driven%20Multi-touch%20Attribution%20Models.pdf)：先理解 MTA 的问题定义与稳定性。
2. [Mapping the Customer Journey](/research/mta/Mapping%20the%20customer%20journey.pdf)：了解基于图和 Markov Chain 的归因研究。
3. [Shapley Value Methods for Attribution Modeling](/research/mta/Shapley%20Value%20Methods%20for%20Attribution%20Modeling%20in%20Online%20Advertising.pdf)：了解 Shapley Value 归因背景。
4. [Data-driven MTA 学习笔记](data-driven-mta-models-study-note.md)：个人笔记，仅用于辅助阅读。

当前项目的实际公式、字段和治理状态以 [AMC MTA 参考索引](../../attribution/reference-index.md)为准。
